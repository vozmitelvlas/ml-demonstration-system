# Использование Triton Inference Server в Docker

## Установка

Triton Inference Server установлен в Docker. При построении проекта Triton будет автоматически установлен.

## Запуск

Для запуска Triton используйте следующую команду:

```bash
docker compose up -d
```

После выполнения этой команды Triton запустится в фоновом режиме.

## Проверка работоспособности

Чтобы убедиться в корректной работе Triton, выполните команду:

```bash
docker logs triton_inference
```

Обратите особое внимание на **таблицу моделей**. Если все работает корректно, напротив каждой модели будет указан статус `READY`.

## Генерация моделей

Поскольку модели получились достаточно объемными, были созданы скрипты для генерации моделей в формате **ONNX**.

Запуск генерации модели:

```bash
python generate_model_onnx_audio_facebook.py
```

## Дополнительные скрипты

Также доступны скрипты, которые:

- Строят **график**;
- Формируют **спектрограмму**;
- Выполняют **транскрипцию аудиозаписи**.

Примеры использования находятся в папке `audio`.
